# Notre Dame Football Analysis

A static, data-driven dashboard of Notre Dame football history (1887–present), built with vanilla JS and Plotly. `index.html` reads game data from `data.json`, which is refreshed weekly during the season by the scraper in `scripts/scrape_and_update.py` via a scheduled GitHub Action.
